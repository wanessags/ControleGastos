# Controle de Gastos Pessoais

Projeto em HTML, CSS e JavaScript puro para praticar manipulação de DOM, estado, eventos, filtros, resumo financeiro e persistência local.

## Arquivos

- `index.html`: estrutura da aplicação.
- `style.css`: estilos visuais no mesmo padrão da Todo List.
- `script.js`: lógica de cadastro, renderização, filtros, exclusão, resumo e `localStorage`.

## Funcionalidades

- Cadastro de lançamentos com descrição, valor, tipo, categoria e data.
- Renderização dinâmica da lista.
- Filtros por todos, receitas e despesas.
- Resumo automático de receitas, despesas e saldo.
- Exclusão individual de lançamentos.
- Botão para limpar todos os dados.
- Persistência local usando `localStorage`.

Abra o arquivo `index.html` no navegador para executar o projeto.
